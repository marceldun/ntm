# 改进点 v12：Xray 占用 8443 时云盘自动避让

这是从 v11 整合出的完整独立版本，可在全新 Ubuntu/Debian VPS 从零安装，也可直接升级已有环境。v1 至 v11 均原样保留。

## v12 修复内容

- 安装前停止旧云盘服务，再检测真实端口占用；
- 8443 被 Xray 或其他服务占用时绝不停止、修改或覆盖原服务；
- 优先选择 9443、10443，必要时继续自动寻找可用 HTTPS 端口；
- 把最终端口统一写入云盘服务、健康检查、防火墙、本地验证和安装结果；
- 重装时优先沿用上次选择的端口，即使 8443 后来空闲，云盘地址也不会随意变化；
- 安装结束直接打印实际可用的完整云盘网址；
- 自动验证登录、上传、下载、新建文件夹、安卓邀请、移动、删除及异常恢复。

## 保留的完整功能

- v11 的网页根目录新建文件夹后自动向安卓发送 Syncthing 邀请；
- v10 的全选、批量删除、新建文件夹、重命名和批量移动；
- 上传、下载、多选打包、排序、列表和大图模式；
- 默认账号 marcel、默认密码 456qwe456；
- 开机启动、异常自动重启及每分钟低内存健康检查；
- Windows 重启恢复、多 VPS 和双向同步；
- 不修改浏览器下载路径。

## 安装后地址

安装器最后输出的“云盘地址”是唯一需要使用的地址。例如：

- 8443 空闲：HTTPS VPS-IP 端口 8443；
- 8443 被 Xray 占用：HTTPS VPS-IP 端口 9443。

无需手动选择端口，也无需停止 Xray。

## 验证

自动测试先用独立服务占住 8443 模拟 Xray，再执行完整安装。测试必须确认占用服务仍然运行、云盘改用 9443、所有功能通过，并且再次安装后仍保持 9443。
