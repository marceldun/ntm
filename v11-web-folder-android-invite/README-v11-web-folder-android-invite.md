# 改进点 v11：网页新建文件夹自动向安卓发送共享邀请

这是从 v10 整合出的完整独立版本，可在全新 Ubuntu/Debian VPS 从零安装，也可直接升级已有环境。v1 至 v10 均原样保留。

## v11 修复内容

- 在网页云盘根目录点击“新建文件夹”后，自动创建独立的 Syncthing 文件夹配置；
- 自动把该文件夹共享给安装时配置的安卓设备；
- 写入后再次读取 Syncthing 配置，确认安卓设备确实在共享列表中；
- 网页明确显示“手机共享邀请已发送”；
- 新建失败或邀请写入失败时自动撤销空文件夹，避免网页显示成功但手机没有邀请；
- 根目录共享文件夹重命名时自动更新 Syncthing 路径和名称；
- 把共享文件夹移入其他文件夹或删除时自动清理 Syncthing 配置；
- 把普通子文件夹移动到云盘根目录时自动生成新的手机共享邀请。

## 保留的完整功能

- v10 的全选、批量删除、新建文件夹、重命名及批量移动；
- 上传、下载、多选打包、排序、列表和大图模式；
- 固定 HTTPS 8443、默认账号 marcel、默认密码 456qwe456；
- 云盘开机启动、异常自动重启及每分钟健康检查；
- 安卓任意文件夹自动接收、Windows 重启恢复、多 VPS 和双向同步；
- 不修改任何浏览器下载路径。

## 使用方式

在 VPS 的 root 终端运行发布版本提供的一行命令。已有文件及手机、电脑同步配置会保留。

以后只需在网页云盘的“我的存档”根目录点击“新建文件夹”。手机 Syncthing-Fork 在线后会收到该文件夹的共享邀请。

## 验证

自动测试会启动两台真实 Syncthing 实例，分别模拟 VPS 和安卓手机。网页创建文件夹后，测试必须在模拟安卓端的 pending folders 接口中读取到该文件夹及 VPS 来源设备，才会通过。
