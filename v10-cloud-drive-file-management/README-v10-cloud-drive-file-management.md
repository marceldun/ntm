# 改进点 v10：云盘文件管理功能

这是从 v9 整合出的完整独立版本，可在全新 Ubuntu/Debian VPS 从零安装，也可直接升级已有环境。v1 至 v9 均原样保留。

## v10 新增功能

- 文件和文件夹一键全选、取消全选，列表表头也提供全选框；
- 单选或多选文件、文件夹后永久删除，并在删除前明确确认；
- 电脑网页和手机网页均可直接新建文件夹；
- 单个文件或文件夹重命名；
- 单选或多选文件、文件夹后移动到云盘内任意文件夹；
- 同名覆盖、非法名称、路径越界及把文件夹移动到自身内部均会被阻止；
- 所有管理操作直接作用于 Syncthing 同一份目录，会自动同步到手机和电脑。
